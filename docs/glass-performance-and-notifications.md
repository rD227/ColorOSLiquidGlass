# 1.3.1 / 1.3.2：性能与通知背景修改说明

## 1. 模糊：先修正图片的归属，再减少处理像素

原来 `BackdropBlur.blur()` 可以直接修改传入的可变 Bitmap；而
`GlassDrawable.blurredBackdrop()` 只在返回另一张图片时才保存缓存。
采样图通常是可变的，因此这条路径会修改采样器拥有的原图，还可能在下一次绘制时再次模糊它。

新路径 `blurCopy()` 创建独立图片，原采样图始终由采样器管理。模糊结果按
“原图对象、原图 generationId、模糊半径”缓存：同一个 Bitmap 被采样器写入新像素后，
generationId 会变化，旧的模糊缓存便失效。

有模糊时，按模糊半径降低处理分辨率，最多将宽高分别降到约八分之一。
半径也转换为缩小后的图片单位。AGSL 采样坐标同时缩放，直接读取小纹理，
不再把 CPU 模糊结果放大成一张全尺寸图片。轮廓与高光仍由原尺寸的绘制路径决定。

这会牺牲一部分背景细节，换取更少的像素运算和临时数组。无模糊时保持原采样图。

## 2. 翻页：已回滚滚动期间冻结纹理的策略

原提交 `b74f25c` 在滚动位置变化期间复用旧纹理，位置停止变化后重新采样。
这违反了运动过程中背景采样应跟随位置变化的要求：旧画面冻结后突然更新，实机表现为间歇跳变。
已单独回滚该提交，删除 `PageCapturePolicy`，恢复原有采样调度。
保留独立低分辨率模糊纹理及其 generationId 缓存；源图更新时缓存仍会失效。

## 3. 通知：为普通卡片增加独立渲染器

原模块已有锁屏胶囊背景处理，但没有普通通知列表卡片的绘制入口。
`ModuleMain` 增加 `NotificationBackgroundView.onDraw(Canvas)` Hook，
具体绘制交给独立的 `NotificationCardGlass`。

渲染器读取系统实际高度、宽度、圆角、透明度和上下裁剪量，绘制卡片背景。
不替换 OEM 的 `mBackground` 对象，系统仍可对该对象执行着色及状态更新。
这个入口替换了原背景的 onDraw，所以 OEM 背景上的按压波纹等附加效果仍需实机检查；
通知的文字和按钮属于其他 View，不由这个渲染器绘制。

每张卡片的状态由 View 的附着监听器持有，查找表使用弱引用；卡片移除时释放采样注册。
进入锁屏时改用锁屏壁纸，解锁后改用桌面壁纸。切换壁纸来源必须让缓存失效，
即使卡片位置和尺寸都没有变化，也不能继续使用之前的图片。

新增“通知卡片与锁屏通知”开关，并让已有锁屏胶囊遵循该开关。
目前普通通知的背景源是壁纸，尚未实现对前台应用实时画面的采样。

### 1.3.2：解锁后夜间通知过亮

原渲染器保留了尺寸与透明度，却遗漏了系统背景的深色外观：直接读取亮壁纸，
同时通知文字仍使用系统夜间模式的白色，导致文字与底板缺乏对比。
`NotificationGlassAppearance` 现在仅在“已解锁且夜间模式”时，为背景绘制使用
RGB 保留 35% 的颜色滤镜。纯白像素变为约 RGB 89，保留纹理、折射和原有 alpha；
不增加截图、CPU 模糊、位图复制或计时刷新。此系数是本模块的深色材质设计值，
并非从 OEM 读取的参数；最终文字对比仍受玻璃透明度、反光及系统文字透明度影响。

滤镜在背景着色后生效，普通位图和尚无采样帧的底色也采用同样处理。
细边高光仍保留。每次绘制根据当前锁屏与主题状态选择滤镜，恢复锁屏或日间时清除，
因此复用的通知卡片不会残留夜间着色。共享壁纸像素、桌面玻璃和通知文字不受此处理影响。

## 4. 验证及边界

`tests/device/GlassPerformanceProbe.java` 在手机真实 Android Bitmap 实现上检查：
原图不被修改、重复模糊结果一致、缩小后的尺寸、零模糊。
复现命令见 `tests/device/README.md`。
`NotificationAppearanceProbe` 使用真实 Android Canvas 检查亮底白字对比、淡出 alpha，
以及同一画笔在锁屏/解锁、夜间/日间之间切换时清除或恢复滤镜。

在连接的一加 PLK110 上，对 512×384 图片执行 32 像素模糊半径，预热后取 12 次测量的中位值：
原全尺寸模糊约 8.98 ms，新低分辨率模糊约 0.20 ms。这是独立步骤计时，不是整体界面帧率。

已核对手机 SystemUI APK 中存在通知 Hook 依赖的方法和字段。真实通知渲染、分组展开、
滑动删除、主题兼容性、锁屏切换及按压效果仍需要安装新包后验证。

`coloros-liquid-glass-release.jks`，别名为 `colorosliquidglass`。
